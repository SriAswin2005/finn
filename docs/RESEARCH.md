# Primary-source research implementation

One annual report and up to two available earnings-call transcripts are discovered from the dedicated Screener document sections. Discovery is generic for NSE symbols; consolidated lookup falls back to standalone when necessary. Secondary company summaries, machine-generated Screener pros/cons, financial tables, presentations, recordings and news are excluded from the corpus.

PDF downloads validate public HTTPS destinations and common private-address ranges, including redirect targets. No user-supplied URL endpoint is exposed. BSE's transcript-viewer links are normalized to its verified direct attachment path. Annual-report downloads are capped at 50 MB, transcripts at 25 MB; parsing is a separate bounded Python process using pypdf 6.10.0. It preserves physical PDF page numbers, limits pages/text/time, and rejects unusable text layers. No OCR is claimed. Basic issuer matching checks the document's opening pages against the discovered company name; this is a screening check, not a cryptographic issuer guarantee.

PDF SHA-256 identifies immutable text extraction caches. Recent identical discovered URLs reuse documents. Downloaded PDF/full text live in ignored local cache. The three committed examples contain selected source pages, fetch times, original links, hashes and parser version. A fresh release can demonstrate Research without external source access. Arbitrary questions on recorded-only evidence search the selected pages, not the entire original report; unknown passages produce an empty evidence state.

Keyword retrieval groups passages under business, financial/trends, management outlook, opportunities and risks. These are excerpts, not generated answers or financial comparisons. A question adds relevant matching passages. Source currency, units, periods and consolidation context must be checked in the original; the retrieval stage does not flatten tables into invented ratios.

Retrieval version v2 prefers explicit numerical guidance ranges and selects a passage from each available transcript before filling extra slots from one call. Financial context includes the latest available call and an annual report when both match. This supplies earlier/later source coverage for reasoning; it does not establish that an annual promise has been met by one quarter. Unsupported AI sections are derived from the sections actually covered by validated claims, and bull/bear claims must be marked as interpretations.

Gemini synthesis consumes only bounded retrieved primary evidence. UI marks AI interpretations, attaches exact supporting quotes/page links, and lists unsupported sections. Quotes/IDs/numbers are validated, but a human quality check is still required for semantic correctness. Until a configured free-tier key is tested, no actual financial analysis is claimed complete. Guidance-versus-delivery needs compatible observations and promises; the app explicitly says when that comparison has not been established.

The prototype stores one collector's JSON files, not a distributed database. New ticker collection is single-flight and at most one uncached company is collected at a time. Browser requests have loading/timeouts; partial source failures preserve visible coverage warnings. Cache freshness is shown; it does not imply the latest quarter's transcript exists. To refresh a company, use `npm run research:collect -- SYMBOL`.
